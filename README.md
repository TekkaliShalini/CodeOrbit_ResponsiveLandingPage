# 🚀 NOVA – Responsive Landing Page

A modern and responsive landing page designed for a fictional productivity workspace called **NOVA**. The project demonstrates frontend development skills using **HTML5 and CSS3**, with a focus on responsive layouts, clean UI design, Flexbox, CSS Grid, and media queries.

## 📌 About the Project

This project was developed as part of my **Web Development Internship at CodeOrbit Tech**.

NOVA is a fictional productivity workspace designed to help users organize their work, manage tasks, and turn ideas into meaningful progress.

The landing page was created with a clean, modern, and responsive design that adapts to different screen sizes.

## ✨ Features

* 🧭 Responsive navigation bar
* 🎯 Hero section with call-to-action buttons
* ⭐ Trust/brand section
* 💡 Features section
* 🔄 How It Works / workflow section
* 📊 Statistics section
* 💬 Customer testimonial section
* 🚀 Call-to-action section
* 📱 Responsive design for desktop, tablet, and mobile devices
* 🎨 Modern and professional user interface
* 📐 CSS Flexbox and Grid layouts
* 📱 CSS media queries for responsive behavior
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layouts, animations, and responsive design
* **CSS Flexbox** – Navigation and flexible layouts
* **CSS Grid** – Feature and content layouts
* **CSS Media Queries** – Responsive design for different screen sizes
* **Git & GitHub** – Version control and project hosting
* **GitHub Pages** – Website deployment
